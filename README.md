# Pink Tic-Tac-Toe ♡

A cute, pastel-pink two-player Tic-Tac-Toe game made with TypeScript, HTML and CSS.

## Run it

1. Install Node.js if it isn't already installed.
2. Open this project folder in your code editor.
3. Open the terminal in the project folder.
4. Run `npm install`.
5. Run `npm run dev`.
6. Open the local URL Vite shows in your terminal.

## Files

- `index.html`: the small starting page and app container.
- `src/main.ts`: game board, turn switching, winner/draw checks, score and buttons.
- `src/style.css`: cute pink visual styling.
- `tsconfig.json`: TypeScript settings.
- `package.json`: scripts and project dependencies.
